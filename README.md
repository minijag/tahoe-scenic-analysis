# Tahoe Scenic Analysis

Static React website for independent scenic-analysis consulting in the Lake Tahoe Basin.

## Development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

The production-ready static site is generated in `dist/`. Pushes to `main` are automatically deployed to GitHub Pages.

This independent consultancy is not affiliated with or endorsed by the Tahoe Regional Planning Agency (TRPA).
